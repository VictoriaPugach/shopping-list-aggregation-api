# Примеры данных

`aggregate-request.json` содержит синтетический валидный `Recipe` 1.0.0 для API-тестов. Это пример формата, не эталон качества агрегации.

До реализации подготовить набор минимум из трёх рецептов с повторяющимися ингредиентами, разными порциями, синонимами, совместимыми единицами и известными запасами. Зафиксировать ожидаемый JSON результата и правила нормализации до запуска проверки.
