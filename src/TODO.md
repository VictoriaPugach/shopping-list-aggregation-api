# План реализации MVP

1. [ ] Проверить подключение `fropti-core-contracts` и использовать только импортируемый `Recipe`.
2. [ ] Согласовать контракт `ShoppingList`, правила сортировки и представление неизвестных значений.
3. [ ] Подготовить минимум три синтетических или разрешённых рецепта с ручными эталонами списка покупок.
4. [ ] Реализовать пересчёт количеств при известных `servings`; для `servings: null` вернуть документированное неразрешённое значение.
5. [ ] Реализовать детерминированную нормализацию названий и словарь синонимов.
6. [ ] Реализовать только безопасные конверсии `g` ↔ `kg` и `ml` ↔ `l`.
7. [ ] Объединить совпадающие ингредиенты и сохранить происхождение позиции.
8. [ ] Вычитать запасы, не создавая отрицательное количество.
9. [ ] Подключить логику к API и CLI, описать ошибки и обновить примеры.
10. [ ] Дополнить публичные тесты, выполнить `make test` и приложить результаты в PR.

Бонусы после MVP: категории магазина, цены, каталоги товаров, оптимизация маршрута, UI и неявные конверсии на основе пищевой базы.
